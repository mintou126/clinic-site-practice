CONCERNS

このような症状や健診異常はありませんか？

健診で腎機能の異常を指摘された方、
尿の異常、むくみ、高血圧、排尿トラブル、
透析相談など、幅広くご相談いただけます。

健診やかかりつけ医に「腎臓が悪い」といわれた

尿蛋白、血尿、クレアチニン高値、eGFR 低下 などに対して精密検査を行います。

手足のむくみ、高血圧が続く

これらの症状は、腎機能低下のサインかもしれません。

頻尿・排尿時の違和感がある

頻尿、尿漏れ、残尿感、排尿時の痛み、性病などの泌尿器症状にも対応しています。

透析について相談したい

透析導入についての相談、他院からの転院相談、夜間透析の相談などにも対応しております。
